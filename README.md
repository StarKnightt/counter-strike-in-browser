# Counter-Strike in your browser

**Play: https://starknightt.github.io/counter-strike-in-browser/** (desktop browser, click to lock the mouse; deployed from `main` by GitHub Actions)

A single-player, CS2-style round on a Dust II A-site, running in the browser. Three.js r185 + three-mesh-bvh, no framework. The map, weapons, gloved hands, C4 and the bots' bodies were all built procedurally by Python scripts running in Blender (driven through the Blender MCP add-on, later in background mode) and exported to GLB. You spawn CT (sides alternate every round), five T bots push long and short, peek, take cover, plant; you hold the site with an AK-47, an AWP and a knife, or defuse. HUD, radar, killfeed, Valorant-code crosshair, Web Audio engine with occlusion, GTAO / bloom / sun shafts / custom stable PCF shadows, 60 fps on an RTX 4060 at 1080p. No Valve assets.

## Run

```
npm install
npx vite --port 5188        # or: npm run dev
# open http://localhost:5188/ and click PLAY
```

Everything the game needs is in the repo (`public/models/dust2_a.webp.glb` is the 34 MB runtime map). Not included, all regenerable:

- `assets_src/dust2_a.glb` (85 MB source export) -- rebuild with `tools/build_map.py` inside Blender, then `npx @gltf-transform/cli webp assets_src/dust2_a.glb public/models/dust2_a.webp.glb`.
- `tools/texcache/` (~130 MB Poly Haven textures the map script reads) -- `python tools/fetch_textures.py && python tools/grade_textures.py`.
- Review screenshots / videos (`shots/`) and the CS2 reference frames (`_ref/`).

No API keys are needed anywhere: `tools/fs.mjs` uses Freesound's public pages, `tools/fetch_textures.py` uses the public Poly Haven API.

## Controls

- WASD move, Space jump, Shift (or C) crouch, Ctrl walk
- Mouse look, LMB fire / knife slash, RMB: AK aim-down-sights, AWP scope (two zoom levels, then back out), knife heavy stab
- 1 / 2 / 3 weapons (AK / AWP / knife), Q last weapon, mouse wheel cycles
- R reload, E hold to defuse (CT) or plant (T, inside the A zone)
- Esc releases pointer/fullscreen; click to resume; click after the result card to start the next round

URL parameters: `?explore=1` (walk the map alone, god mode) · `?bots=easy|normal|hard` · `?side=t|ct` · `?nolock=1` (no pointer/keyboard lock) · `?sens=2.0` · `?xhair=<valorant code>` · `?scale=1|1.25|1.4` · `?view=x,y,z,yaw,pitch` · `?pcf=stock` · `?aa=msaa|smaa|none` · `?ao=normal|depth`

## Cheats (`window.__game.cheats` in the console)

- `noclip()` toggle fly-through-walls
- `tp(x, y, z)` teleport (y optional)
- `bots(on)` spawn / remove the enemy team
- `god = true|false`
- `sens(v)` sensitivity (persisted)
- `xhair(code)` crosshair code (persisted)
- `difficulty('easy'|'normal'|'hard')` (persisted)
- `side('t'|'ct')` side from the next round (persisted)
- `bomb()` hand the player the C4
- `pos`, `yaw` getters
